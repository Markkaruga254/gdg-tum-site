Type and shape

Fonts
Anton for headlines and numbers (always uppercase). Space Grotesk 400/500/700 for body and labels.
Build. Learn. Ship.
Scale
Hero up to 128px; page titles up to 120px; section titles 48 to 72px; row numbers 56px; body 15 to 18px; labels 12px bold uppercase with 0.5px tracking.
Shape rules
Everything sits in a centered 1280px frame with a 3px ink border. 3px ink borders divide all blocks. Flat colors only: no gradients, shadows or rounded corners (only decorative circles inside illustration shapes). Links turn yellow on hover. Visible focus ring on every control.

Rules for the coding agent

  1. Match this spec exactly: sizes, colors, fonts, borders, spacing, copy and element order. Add nothing, remove nothing.
  2. Bracket or sample text is real data from Firestore. If data is missing, use the shown empty state.
  3. Canonical nav on every page: logo, Events, Tracks, Gallery, Blog, Leads, Labs, a Sign in cell (name plus Sign out when signed in), and the yellow Join a track cell on the right. Active page is yellow.
  4. Not built yet, shown disabled with "Coming soon": RSVP, newsletter and digest, Generate draft with AI (and its counter and generating strip).
  5. The ticker hides when nothing is live. The event page shows only its current state.
  6. Photos are never covered by an overlay. The track color is only the image-error fallback.
  7. Permissions: everyone reads published content. Leads create, edit, publish and unpublish their own track's writeups, events and ticker. Admins do everything, including deletes, roles and partners.
  8. Responsive from 360px to 1280px with no horizontal page scroll. Grids use auto-fit; the nav wraps.
  9. Accessibility: real buttons and links, labelled inputs, text contrast 4.5:1 or better, alt text on every photo, keyboard operable.
  10. Keep every existing behavior, rule and test working. Report any element that cannot match exactly instead of approximating.
